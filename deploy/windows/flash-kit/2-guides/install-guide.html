راهنمای نصب Warehouse OS — سیستم مغازه

فایل‌های لازم داخل همین فلش، پوشهٔ kardo v1 هستند. کل نصب بدون اینترنت انجام می‌شود؛ فقط WebView2 لازم است که ویندوزِ به‌روز معمولاً دارد (مرحلهٔ ۰ چک می‌کند).

مرحلهٔ ۰ — چک قبل از نصب (۲ دقیقه)

فایل 3-scripts\RUN-CHECK-BEFORE-INSTALL.bat را دوبارکلیک کن.
این اسکریپت بررسی می‌کند: حق ادمین، فضای خالی دیسک (حداقل ۱۰ گیگ روی C)، آزاد بودن پورت‌های 3000 و 3001 و 5432، و وجود WebView2.
اگر همه سبز بود برو مرحلهٔ ۱. اگر قرمز داشت، فایل 2-guides\troubleshoot.html را باز کن و خطای متناظر را ببین.

مرحلهٔ ۱ — نصب (۱۰ دقیقه)

۱. روی 1-install\WarehouseOS-Setup-0.4.0.exe راست‌کلیک → Run as administrator.
۲. در صفحهٔ اول ویزارد نوع نصب را بگذار روی Full install (پیش‌فرض) → Next → Install.
۳. صبر کن تا پنجرهٔ سیاه مراحل دیتابیس و سرویس‌ها را انجام دهد و خودش بسته شود.
۴. در انتها فایل INSTALL-INFO.txt باز می‌شود؛ اگر نشد دستی باز کن:
C:\WarehouseOS\INSTALL-INFO.txt
داخلش آدرس پنل و API و محل رمز ادمین نوشته شده. این فایل را عکس بگیر یا پرینت کن.
نصب کامل یعنی: هر سه سرویس WarehouseOS-DB / API / Web در حالت Running باشند. برای چک سریع: 3-scripts\RUN-CHECK-SYSTEM.bat

مرحلهٔ ۱٫۵ — پچ سرویس‌ها (فقط برای نصب‌های قدیمی 0.3.3)

نسخهٔ 0.4.0 اسکریپت اصلاح‌شدهٔ سرویس‌ها را داخل خودش دارد؛ روی نصبِ تازه هیچ کاری لازم نیست.
این مرحله فقط اگر روی یک سیستمِ قبلاً نصب‌شده با 0.3.3 آپدیت می‌کنی لازم است: فایل 3-scripts\RUN-PATCH-SERVICES-SCRIPT.bat را راست‌کلیک → Run as administrator تا اسکریپت اصلاح‌شده جایگزین شود.

مرحلهٔ ۲ — اولین ورود و تغییر رمز (۵ دقیقه)

۱. رمز ادمین یک‌بار در لاگ نوشته شده: فایل C:\WarehouseOS\data\api.log را باز کن و دنبال این خط بگرد:
ادمین پیش‌فرض ساخته شد: admin / XXXXXXXX
۲. در پنل (آدرس از INSTALL-INFO، مثلاً http://192.168.x.x:3001) با admin و آن رمز وارد شو.
۳. بلافاصله از منوی کاربران رمز را عوض کن.
۴. یک کاربر «فروشنده» بساز که فقط صندوق ببیند و رمزش را به فروشنده بده.
رمز ادمین هر نصب، مخصوص همان نصب است. رمزِ لپ‌تاپ روی مغازه کار نمی‌کند.

مرحلهٔ ۳ — وارد کردن کاتالوگ محصولات (۳ دقیقه)

فایل 3-scripts\RUN-RELOAD-CATALOG.bat را راست‌کلیک → Run as administrator.
این اسکریپت ۳۳ هزار کالا (با قیمت و بارکد و خودروها) را از catalog-only.dump داخل دیتابیس می‌ریزد.
بعد از تمام‌شدن، پنل را با Ctrl+R رفرش کن و چند محصول را سرچ کن.

مرحلهٔ ۴ — تنظیم بک‌آپ شبانه (۵ دقیقه)

۱. از منوی مدیریت، مقصد بک‌آپ را روی یک درایوی غیر از C بگذار (مثلاً D یا یک هارد دوم).
۲. بک‌آپ شبانه ساعت ۲۳:۰۰ خودکار اجرا می‌شود؛ یک بار دستی هم از پنل «بک‌آپ بگیر» تا مطمئن شوی فایل ساخته می‌شود.
۳. بعد از بستنِ صندوق هم دیالوگ «بک‌آپ بگیر و ببند» می‌آید — این عمدی است و باید کار کند.

مرحلهٔ ۴٫۵ — آیکون وضعیت سرور (۱ دقیقه)

فایل 3-scripts\INSTALL-STATUS-TOOL.bat را دوبل‌کلیک کن و اجازهٔ ویندوز را بده.
از این به بعد یک نقطهٔ سبز/قرمز کنار ساعت ویندوز می‌ماند:
سبز = سرور فعال · قرمز = سرور قطع · با نگه‌داشتن ماوس روی آن، IP سرور دیده می‌شود
راست‌کلیک → «نمایش وضعیت» یا «تعمیر سرور» — اگر سرویسی خاموش باشد خودش برش می‌گرداند.
شورتکات «Warehouse OS Status» هم روی دسکتاپ ساخته می‌شود.

مرحلهٔ ۵ — شبکه و رزرو IP (۵ دقیقه)

۱. آدرسی که INSTALL-INFO داده (مثلاً 192.168.1.50) را در تنظیمات روتر Static/Reserve کن.
۲. اگر رزرو نکنی، هر بار روشن‌شدن مودم احتمال دارد IP عوض شود و صندوق‌ها و موبایل‌ها قطع شوند.
۳. روی سیستم صندوقِ دوم فقط لازم است همان آدرس پنل را در پنجرهٔ تنظیمات صندوق بدهی.

مرحلهٔ ۶ — تست نهایی قبل از ترک مغازه (۱۰ دقیقه)

این ۵ مورد را حتماً با هم چک کن:
۱. اسکن یک بارکد ← کالا با قیمت بیاید بالا
۲. یک فاکتور نسیه بزن ← در «حساب‌باز» مشتری دیده شود
۳. یک رسید/پرداخت ثبت کن ← مانده همان لحظه صفر شود
۴. پرینت فیش حرارتی بگیر
۵. صندوق را ببند ← اگر دیالوگ بک‌آپ آمد، «بک‌آپ بگیر و ببند» را بزن ← فایل dump در پوشهٔ بک‌آپ ساخته شود
3-scripts\RUN-CHECK-SYSTEM.bat هم بزن و خروجی سبز را ببین.

نصب صندوق روی کامپیوتر دوم (اگر لازم شد)

همان Setup را روی آن سیستم اجرا کن و نوع نصب را Seller app only بگذار.
اولین اجرای صندوق فقط آدرس سرور را می‌پرسد: http://<IP-سرور>:3001

آپدیت‌های بعدی

هر نسخهٔ جدید فقط یک فایل Setup است. روی سیستم سرورِ مغازه:
  1. فایل Setup جدید را روی فلش بگذار (پوشهٔ updates) و به مغازه ببر.
  2. PowerShell را Run as administrator باز کن و بزن:
C:\WarehouseOS\scripts\update.ps1 -Setup E:\kardo v1\updates\WarehouseOS-Setup-0.4.x.exe این دستور خودش: بک‌آپ می‌گیرد → نسخهٔ جدید را نصب می‌کند → مایگریشن دیتابیس را می‌زند → سرویس‌ها را دوباره می‌سازد و بالا می‌آورد → و از نسخهٔ قبلی یک کپی در C:\WarehouseOS\versions نگه می‌دارد.
جزئیات بیشتر: updates\HOW-TO-UPDATE.txt
