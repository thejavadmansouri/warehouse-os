کاردو — کیت نصبی قابل حمل (نسخه {{VERSION}})
==============================================

این پوشه یک نصب کامل و مستقل است. هیچ چیزی روی ویندوز نصب نمی‌کند:
نه سرویس، نه پستگرسِ سیستمی، نه Node روی PATH، نه دسترسی مدیر.
همه چیز — Node، PostgreSQL و خودِ برنامه — داخل همین پوشه است.
یعنی می‌توانی کل پوشه را روی فلش بگذاری، به لپ‌تاپ دیگر ببری و همان‌جا اجرا کنی.


راه‌اندازی (سه قدم، یک بار)
--------------------------
1) پوشه را روی لپ‌تاپ مقصد کپی کن (هر جایی، مثلاً C:\Kardo).
   مهم: پوشه را داخل Program Files نگذار.

2) روی install.bat دوبار کلیک کن.
   - اگر ویندوز پرسید «Run as administrator»، جواب نده — عمداً مدیر لازم نیست.
     پستگرس با دسترسی مدیر بالا نمی‌آید و نصب با خطا متوقف می‌شود.
   - نصب یک تا سه دقیقه طول می‌کشد (ساخت دیتابیس + همه‌ی جدول‌ها).
   - آخرش یک پنجره‌ی مرورگر روی صفحه‌ی ورود باز می‌شود.

3) وارد شو:
      نام کاربری: admin
      رمز:        در فایل INSTALL-INFO.txt نوشته شده (و در همان پنجره‌ی نصب هم چاپ شد)
   همان بار اول رمز را از پنل عوض کن.


هر روز
------
  start.bat   → دیتابیس + سرور + پنل بالا می‌آید و مرورگر باز می‌شود
  stop.bat    → همه‌چیز مرتب خاموش می‌شود (داده‌ها دست نمی‌خورند)

اگر لپ‌تاپ را خاموش کنی، دفعه‌ی بعد فقط start.bat را بزن.


آدرس‌ها
-------
  روی همین لپ‌تاپ:   http://127.0.0.1:3001
  از گوشی/تبلت در وای‌فای:  http://IP-لپ‌تاپ:3001
  آدرس API برای اپ اندروید:  http://IP-لپ‌تاپ:3000

start.bat خودش IP شبکه را نشان می‌دهد. اگر گوشی وصل نمی‌شود، معمولاً فایروال
ویندوز جلوی پورت ۳۰۰۰/۳۰۰۱ را گرفته؛ یک بار اجازه بده.


داده‌ها کجا هستند
-----------------
  data\pg\        دیتابیس (تنها جای داده‌های واقعی)
  config\.env     رمزها — گمش کنی، دیتابیس باز نمی‌شود. از این فایل نسخه‌ی پشتیبان بگیر.
  backups\        پشتیبان‌های شبانه
  data\*.log      لاگ سرور، پنل و دیتابیس

برای انتقال داده به لپ‌تاپ دیگر: کل پوشه را با data و config کپی کن و
همان‌جا start.bat را بزن (install.bat لازم نیست، چون config\.env از قبل هست).


اگر بالا نیامد
--------------
  data\install.log   رونوشت کامل نصب
  data\db.log        خطای دیتابیس
  data\api.log       خطای سرور (اولین ورودِ admin هم اینجا نوشته می‌شود)
  data\web.log       خطای پنل

پورت‌ها
-------
  ۳۰۰۰ سرور API، ۳۰۰۱ پنل، ۵۴۳۳ دیتابیس (فقط روی خودِ لپ‌تاپ، از شبکه بسته است).
  ۵۴۳۳ عمداً انتخاب شده تا با پستگرسِ نصب‌شده روی لپ‌تاپ (۵۴۳۲) تصادم نکند.
