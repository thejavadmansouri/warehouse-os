# 📦 راهنمای ابزار استخراج جامع اطلاعات پارسیان (Parsian Exporter)

این ابزار برای استخراج **کامل و بدون نقص** تمام داده‌های نرم‌افزار حسابداری پارسیان (شامل قیمت خرید و فروش واقعی، کاتالوگ کالاها، قفسه انبار، مشتریان، فاکتورها، چک‌ها و کدینگ حساب‌ها) طراحی شده است.

---

## 🚀 نحوه اجرا روی سیستم دارای پارسیان (فقط ۲ مرحله):

1. **کپی کردن پوشه:**  
   کل پوشه `parsian-exporter` را روی یک فلش‌مموری کپی کنید و به کامپیوتری که پارسیان روی آن نصب است ببرید.
2. **اجرا:**  
   روی فایل **`RUN_EXPORT.bat`** دابل کلیک کنید.

---

## 🌟 چه اطلاعاتی استخراج می‌شود؟

اسکریپت به صورت کاملاً خودکار به دیتابیس SQL Server پارسیان وصل شده و یک پوشه حاوی فایل‌های زیر تولید می‌کند:

| نام فایل | محتوا و فیلدها |
|---|---|
| `01_products.json` و `.csv` | کد کالا، نام، شماره فنی، بارکد، **آدرس قفسه (`ShelfLocation`)**، **آخرین قیمت خرید واقعی از فاکتورها (`LastRealPurchasePrice`)**، قیمت فروش، و **موجودی فیزیکی محاسبه‌شده انبار (`CalculatedCurrentStock`)** |
| `02_customers_and_suppliers.json` و `.csv` | نام مشتری/فروشنده، شماره تلفن ثابت، موبایل، آدرس، کد ملی، کد پستی و **مانده بدهکاری/بستانکاری نهایی** |
| `03_purchase_invoices.json` و `.csv` | تمام فاکتورهای خرید با جزئیات اقلام، تعداد، قیمت خرید واقعی، شماره فاکتور و نام تأمین‌کننده |
| `04_sale_invoices.json` و `.csv` | تمام فاکتورهای فروش با جزئیات اقلام، قیمت فروش، تخفیفات و نام مشتری |
| `05_cheques.json` و `.csv` | تمام چک‌های دریافتی و پرداختی با شماره چک، شناسه صیاد، تاریخ سررسید، مبلغ، بانک و وضعیت وصول/برگشت |
| `06_chart_of_accounts.json` و `.csv` | درختواره کامل حسابداری (کل، معین، تفصیلی) |
| `00_REPORT_SUMMARY.txt` | گزارش آماری فارسی از تعداد رکوردهای استخراج‌شده جهت اطمینان از صحت اطلاعات |

> [!TIP]
> تمام فایل‌های CSV خروجی با استاندارد **UTF-8 with BOM** تولید می‌شوند تا وقتی مستقیماً در **اکسل (Excel)** باز می‌شوند، متن‌های فارسی بدون کوچک‌ترین به‌هم‌ریختگی و با فونت خوانا نمایش داده شوند.
