# راهنمای آموزشی کاردو (فارسی)

این پوشه شامل راهنمای کاربری فارسی سیستم **کاردو / Warehouse OS** است.

| فایل | توضیح |
|------|-------|
| `راهنمای-کاردو.pdf` | نسخهٔ نهایی ۲۴ صفحه‌ای، A4، راست‌چین، با فونت وزیر |
| `kardo-guide.html` | سورس HTML راهنما (قالب طراحی، بدون فونت جاسازی‌شده) |
| `build-pdf.mjs` | اسکریپت ساخت PDF از HTML با Edge/Chrome headless |

## ساخت مجدد PDF

```powershell
node docs\training\build-pdf.mjs
```

اسکریپت فونت‌های `Vazir Regular` و `Vazir Bold` را از `C:\Windows\Fonts`
می‌خواند و داخل PDF جاسازی می‌کند. خروجی در همین پوشه ساخته می‌شود.
