فهرست پیشنهادها — کدام‌ها اجرا شده، کدام‌ها در انتظار شما

  1. ✅حذف نشانِ DEV — از پایینِ صفحه پاک شد.
  2. ✅بیپِ اسکن — موفق یک بیپِ بلند، خطا دوبیپِ بم؛ Ctrl+B خاموش/روشن.
  3. ✅نشانگرِ اتصالِ realtime — نقطه‌ی سبز/قرمز کنار اسکن + جبرانِ رویدادهای گم‌شده بعد از قطعی.
  4. ۴زنجیره‌ی ستون‌ها ۱→۲→۳→۴ — تخفیف هم وارد پیمایش شود (الان فقط تا قیمت می‌رود).
  5. ۵Ctrl+D تکرارِ ردیفِ فعال + Enter در تعداد ← ردیفِ بعدی.
  6. ۶دستور ۳*۴۵۰۰۰۰ در نوار اسکن + ‎+۳ برای افزودن به تعدادِ فعال.
  7. ۷رسید حرارتی ۸۰mm — برگه‌ی فشرده برای فروشِ گذری + چاپِ خودکارِ اختیاری.
  8. ۸قیمت عمده برای دسته‌ی عمده + برچسب روی ردیف + Alt+P برگشت به خرده.
  9. ۹هشدارِ موجودیِ کم — فقط وقتی کم است: زردِ کوچکِ «۳ مانده» کنار نام کالا.
  10. ۱۰سوییچِ سریع انبار — اگر بیش از یک انبار دارید، F9 بین انبارها.

اعداد ۱..۴ که روی ستون‌ها کشیدید را همین‌طور خواندم: کالا ← تعداد ← قیمت ← تخفیف — پیشنهاد ۴ دقیقاً همان است. اگر منظورتان چیز دیگری بود، بگویید.
