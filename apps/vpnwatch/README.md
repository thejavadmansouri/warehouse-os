# VpnWatch 🔍

اپ نظارت بر آی‌پی و VPN در نوار بالای مک — با **کیلسوییچ**.

هر لحظه آی‌پی عمومی شما را بررسی می‌کند و کنار آیکن زبان، یک چراغ وضعیت نشان می‌دهد:

| چراغ | معنی |
|------|------|
| 🟢 سبز | آی‌پی در کشورهای مجاز است (پیش‌فرض: انگلیس GB) |
| 🔴 قرمز | کشور آی‌پی **غیرمجاز** است + نوتیفیکیشن هشدار |
| ⚪ خاکستری | اینترنت قطع / سرویس جواب نده / کشوری مشخص نشود |

کنار چراغ، کد کشور فعلی هم نمایش داده می‌شود (مثلاً `GB` یا `IR`).

## 🔒 کیلسوییچ

وقتی کیلسوییچ فعال باشد و چراغ **قرمز** شود، وای‌فای **خودکار قطع** می‌شود تا ترافیک نشت نکند. با برگشتن به کشور مجاز (یا دکمه «بازیابی اینترنت») وای‌فای دوباره روشن می‌شود.

نصب: یک‌بار از منو → «کیلسوییچ 🔒» → «نصب کیلسوییچ» — رمز مدیر را می‌خواهد و یک قانون sudoers محدود می‌سازد که فقط همین اسکریپت کمکی را بدون رمز اجرا کند. رمز ذخیره نمی‌شود.

## امکانات منو

- نمایش آی‌پی، کشور، ISP و زمان آخرین بررسی
- «بررسی الان» (⌘R)
- فاصله بررسی: ۳۰ ثانیه / ۱ دقیقه / ۵ دقیقه
- کشورهای مجاز: انتخاب از لیست (GB, IE, DE, NL, US, TR, AE, IR) یا افزودن کد دلخواه
- تاریخچه: آخرین ۵۰ تغییر (نمایش ۲۰ تای آخر)
- اجرای خودکار با روشن شدن مک (LaunchAgent)
- هشدار هنگام آی‌پی غیرمجاز (قابل خاموش‌کردن)
- کیلسوییچ 🔒

## سرویس‌های تشخیص کشور

1. **ipwho.is** — اصلی (رایگان، بدون کلید)
2. **ip-api.com** — جایگزین
3. **ipinfo.io** — جایگزین نهایی

## اجرا

```bash
npm install
npm start          # اجرای توسعه‌ای
npm run build      # ساخت VpnWatch.app در dist/
open dist/VpnWatch.app
```

## ساختار فایل‌ها

- `main.js` — فرایند اصلی: چراغ نوار، منو، تایمر، نوتیفیکیشن، کیلسوییچ
- `geo-service.js` — تشخیص کشور (۳ سرویس با failover)
- `store.js` — ذخیره تنظیمات و تاریخچه (JSON در userData)
- `kill-switch.js` — نصب sudoers + قطع/وصل وای‌فای
- `scripts/` — اسکریپت‌های کمکی کیلسوییچ
- `country-dialog.html` + `preload.js` — دیالوگ افزودن کشور دلخواه

## نکته

این اپ فقط **نظارت و هشدار** می‌کند — خودش VPN را قطع/وصل نمی‌کند (کار برنامه VPN شماست). کیلسوییچ هم فقط وای‌فای را قطع می‌کند؛ اگر بخواهید اترنت یا کل شبکه را هم قطع کند، اسکریپت `scripts/vpnwatch-killswitch.sh` قابل توسعه است.
