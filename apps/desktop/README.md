# اپ فروشنده (ویندوز) — قاب Tauri v2

اپ وب موجود (`apps/web`) را در یک قاب دسکتاپ ویندوز اجرا می‌کند. اپ وب بازنویسی نشده —
فقط قابش ساخته شده. تنها دلیل واقعی دسکتاپ بودن، **دسترسی به فیش‌پرینتر ESC/POS** است
که از مرورگر ممکن نیست.

## وضعیت

⚠️ **این کد روی ویندوز کامپایل و تست نشده.** روی مک نوشته شده و Rust روی این ماشین نصب
نیست. معماری و منطق بازبینی‌شده است، ولی اولین `cargo build` روی ویندوز ممکن است به
اصلاحات کوچکی در امضای توابع کریت `windows` نیاز داشته باشد (این کریت بین نسخه‌ها
امضاها را عوض می‌کند). بقیه‌ی کد به آن وابسته نیست.

## پیش‌نیازهای ویندوز

1. Rust از طریق [rustup](https://rustup.rs)
2. Visual Studio Build Tools با بار کاری «Desktop development with C++»
3. WebView2 — روی ویندوز ۱۰/۱۱ از پیش هست
4. برای خروجی `.msi`: WiX Toolset v3 (برای `.exe` لازم نیست)

## نصب و اجرا

**پروژه فقط npm است. هرگز `bun` اجرا نکن** — دو بار مدیر بسته، `node_modules` را خراب
می‌کند و کلاینت Prisma را از اسکیمای اشتباه می‌سازد (`docs/AI_HANDOFF.md` §4).

```bash
npm install
```

### حالت توسعه

دو ترمینال لازم است.

```bash
cd apps/web && npm run dev
```

```bash
cd apps/desktop && npm run dev
```

در حالت توسعه همیشه به `http://localhost:3001` وصل می‌شود و آدرس تنظیم‌شده نادیده
گرفته می‌شود.

### آیکون

یک بار قبل از اولین بیلد:

```bash
cd apps/desktop && npm run icons
```

### بیلد نصب‌کننده

```bash
cd apps/desktop && npm run build
```

خروجی در `src-tauri/target/release/bundle/` — هم `nsis/*.exe` و هم `msi/*.msi`.

نصب‌کننده روی حالت **currentUser** تنظیم شده، پس نصب نیاز به دسترسی ادمین ندارد.

## اولین اجرا روی سیستم فروشنده

آدرس سرور داخل نصب‌کننده نیست. اولین بار که برنامه باز می‌شود، چون آدرسی ذخیره نشده،
**پنجره‌ی تنظیمات** باز می‌شود:

1. آدرس سرور را وارد کن — نوشتن `http://` لازم نیست (`192.168.1.50:3000` کافی است).
2. «تست اتصال» بزن.
3. پرینتر فیش را انتخاب کن و «چاپ آزمایشی» بگیر.
4. «ذخیره و ورود» — پنجره‌ی اصلی باز می‌شود.

بعداً از منوی **برنامه ← تنظیمات اتصال و پرینتر** قابل تغییر است.

## میانبرها

| کلید | کار |
|---|---|
| `F11` | تمام‌صفحه |
| `Ctrl+R` | بارگذاری مجدد |

میانبرها داخل خود پنجره گرفته می‌شوند، نه با global shortcut — میانبر سراسری کلید را از
کل ویندوز می‌دزدد حتی وقتی برنامه فوکوس ندارد.

## دستورهای قابل صدا زدن از اپ وب

```js
const { invoke } = window.__TAURI__.core;

await invoke('print_receipt', { bytes: [...] });  // آرایه‌ی بایت ESC/POS
await invoke('list_printers');                    // [{ name, is_default }]
await invoke('test_print');
await invoke('get_config');                       // { server_url, printer_name }
await invoke('open_settings');
await invoke('toggle_fullscreen');
```

تشخیص اینکه داخل قاب دسکتاپ هستیم یا مرورگر معمولی:

```js
const isDesktop = typeof window !== 'undefined' && !!window.__TAURI__;
```

اپ وب باید بدون Tauri هم کار کند — پنل مدیر در مرورگر باز می‌شود. دکمه‌ی چاپ فیش فقط
وقتی نشان داده شود که `isDesktop` درست باشد.

## چند تصمیم و دلیلشان

**چاپ خام (RAW) است، نه چاپ گرافیکی.** فیش‌پرینتر حرارتی بایت‌های ESC/POS را مستقیم
می‌خواهد. اگر از مسیر معمولی چاپ ویندوز برود، درایور آن را به تصویر تبدیل می‌کند و
دستورهای برش کاغذ، کشوی پول و متن فشرده از بین می‌روند. بنابراین با
`datatype = "RAW"` به spooler داده می‌شود.

**روی غیرویندوز، چاپ خطا برمی‌گرداند و هرگز موفق نمی‌شود.** اگر بی‌صدا `Ok` بدهد،
برنامه می‌گوید «چاپ شد» و هیچ فیشی چاپ نمی‌شود — بدترین حالت ممکن.

**تنظیمات کنار فایل `exe` ذخیره نمی‌شود.** اگر برنامه در `Program Files` نصب شود آن
مسیر بدون ادمین نوشتنی نیست و ذخیره بی‌صدا شکست می‌خورد. به‌جایش پوشه‌ی تنظیمات
کاربر استفاده می‌شود.

**capability بخش `remote.urls` دارد.** صفحه از سرور راه دور بارگذاری می‌شود، پس مبدأ
وب‌ویو «راه دور» است؛ بدون این بخش صفحه اصلاً نمی‌تواند `invoke` بزند و چاپ کار
نمی‌کند. الگو فعلاً باز است چون آدرس سرور را کاربر تنظیم می‌کند — اگر آدرس سرورت ثابت
است، در `capabilities/main.json` به همان آدرس محدودش کن.
