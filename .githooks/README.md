# قلاب‌های گیت — گارد ورود به مخزن

این پوشه یک گارد دارد که جلوی رسیدن سه چیز به مخزن **عمومی** را می‌گیرد: توکن و رمز، فایل‌های نصب/باینری، و فایل‌های سنگین.

## فعال کردن (یک بار برای هر clone)

```bash
git config core.hooksPath .githooks
```

`core.hooksPath` یک تنظیم محلی است و همراه مخزن نمی‌آید، پس روی هر ماشین تازه باید همین یک خط اجرا شود. بعد از آن:

| قلاب | کِی اجرا می‌شود | چه چیزی را می‌بیند |
|---|---|---|
| `pre-commit` | پیش از ساخته‌شدن کامیت | دقیقاً همان چیزی که در این کامیت می‌نشیند (`git diff --cached`) |
| `pre-push` | پیش از فرستادن به ریموت | کامیت‌هایی که ریموت هنوز ندارد — نه کل تاریخچه، وگرنه هر push دوباره همان یافته‌های قدیمی را گزارش می‌کرد |

هر دو یک فایل را صدا می‌زنند: `guard.mjs`. هیچ وابستگی npm ندارد و همهٔ تطبیق‌ها را به موتور `git grep` می‌سپارد، پس روی Git Bash ویندوز و روی مک یکسان رفتار می‌کند.

## چه چیزی مسدود می‌شود

**با نام فایل:** `.env` و هر `.env.*` جز `.env.example` — `*.pem`, `*.key`, `*.p12`, `*.pfx`, `*.jks`, `*.keystore`, `*.ppk`, `id_rsa` و هم‌خانواده‌هایش — `login.json`, `token.txt`, `net-token.txt`, `credentials.json`, `service-account*.json`, `.npmrc`, `.netrc` — و پسوندهای ساختنی: `exe, dll, msi, zip, 7z, rar, iso, tar, gz, tgz, dump, bak, apk, aab, jar`.

**با محتوا:** JWT، توکن گیت‌هاب (`ghp_`/`gho_`/`ghs_`/`github_pat_`)، کلید AWS، توکن Slack، کلید `sk-`، توکن ربات تلگرام، بلوک کلید خصوصی، و آدرس PostgreSQL که **رمز واقعی** در آن نوشته شده باشد (جای‌نگهدارهای `$dbPassword`، `USER:PASSWORD` و `...` عمداً عبور می‌کنند).

**با حجم:** بالای ۵ مگابایت مسدود، بالای ۱ مگابایت فقط اخطار. سقف را می‌شود با `WOS_GUARD_MAX_MB` عوض کرد.

دو مورد آخر «اخطار» هستند نه «سد»: `Authorization: Bearer <token>` و انتساب یک رشتهٔ بلند به نامی شبیه رمز. اینها جای واقعی هم دارند (مثلاً در تست)، پس فقط یادآوری می‌کنند.

## چه چیزی مسدود **نمی‌شود**

عمداً محافظه‌کار است، چون گاردی که در کار روزمره سر و صدا کند، در نهایت با `--no-verify` دور زده می‌شود:

- `.env.example` و هر فایل `.example` (نمونه باید در گیت باشد).
- فونت‌ها، تصاویر و آیکون‌ها؛ این مخزن عمداً `logo.png`، `icon.icns` و `Vazirmatn-*.woff2` دارد.
- فایل‌های مهاجرت `.sql` زیر `prisma/migrations/` (سورس‌اند، نه دامپ).
- سکرت‌هایی که در کامیت‌های قدیمی‌اند و در این push تکرار نشده‌اند — این گارد جلوی **گذشته** را نمی‌گیرد، فقط جلوی **بعدی** را.

## وقتی چیزی مسدود شد

```
fix     : خط‌های مشکل‌دار را بردارید، یا با `git rm --cached <path>` فایل را فقط روی دیسک نگه دارید
allow   : همان مسیر دقیق را با یک خط توضیح به .githooks/allowlist.txt اضافه کنید
override: git commit --no-verify   /   git push --no-verify
```

اگر واقعاً باید دور بزنید، دلیلش را در متن کامیت بنویسید — چون مخزن عمومی است و این توکن‌ها بعد از push فقط با باطل‌کردن پاک می‌شوند، نه با حذف فایل.
